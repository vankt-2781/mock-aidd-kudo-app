## Architecture
Next app reads `NEXT_PUBLIC_SUPABASE_URL` + `NEXT_PUBLIC_SUPABASE_ANON_KEY` (`.env.local`). Supabase local reads `GOOGLE_CLIENT_ID/SECRET` (`supabase/.env`). Google redirects to `http://127.0.0.1:54321/auth/v1/callback`; Supabase then redirects to `http://localhost:3000/auth/callback`.

## Related Code Files (ownership)
- Modify: `package.json`, `package-lock.json`, `.gitignore`
- Create: `supabase/config.toml` (via `npx supabase init`), `.env.example`, `supabase/.env.example`, `vitest.config.ts`, `docs/supabase-google-oauth-setup.md`

## Implementation Steps
1. `npm i @supabase/ssr @supabase/supabase-js` ; `npm i -D supabase vitest`.
2. Add scripts: `"test": "vitest run"`, `"supabase": "supabase"`.
3. `vitest.config.ts`: node env, `@/` alias → `src/`, include `src/**/*.test.ts`.
4. `npx supabase init` → edit `supabase/config.toml`:
   - `[auth] site_url = "http://localhost:3000"`, `additional_redirect_urls = ["http://localhost:3000/auth/callback"]`
   - `[auth.external.google] enabled = true`, `client_id = "env(GOOGLE_CLIENT_ID)"`, `secret = "env(GOOGLE_CLIENT_SECRET)"`, `redirect_uri = ""` default; set `skip_nonce_check` only if docs require for local.
5. `.env.example`: `NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:54321`, `NEXT_PUBLIC_SUPABASE_ANON_KEY=` (from `npx supabase status`). `supabase/.env.example`: `GOOGLE_CLIENT_ID=`, `GOOGLE_CLIENT_SECRET=`.
6. `.gitignore`: add `!.env.example`, `!supabase/.env.example`; confirm `supabase/.env` and `.env.local` stay ignored.
7. `docs/supabase-google-oauth-setup.md`: Google Cloud console steps (OAuth client type Web, authorized redirect URI `http://127.0.0.1:54321/auth/v1/callback`), copy envs, `npx supabase start`, restart after env change.
